# YUI — автономный локальный AI-компаньон

Это попытка сделать проект основанный на вайбкоде. Основной код пишется нейросетью, и лишь дорабатывается человеком.

**YUI (Юи)** — локальная цифровая личность для Windows: голосовой собеседник со своим характером, долговременной памятью и доступом к компьютеру. Всё работает офлайн на своём железе — LLM через `llama-server` (llama.cpp), распознавание речи через faster-whisper, голос через Silero. Интернет нужен только для инструментов поиска.

Юи — не ассистент, а персонаж: она говорит по-русски, сама решает, браться ли за просьбу, может промолчать, копит в памяти факты о пользователе и о себе, а её характер со временем дополняется через память.

## Возможности

- **Русский и английский.** Можно говорить на любом из двух языков: язык речи определяется автоматически, Юи отвечает на том же языке и своим голосом для каждого (Silero ru/en).
- **Голос и текст.** Ввод с микрофона (faster-whisper) или с клавиатуры; ответ озвучивается потоково, по предложениям (Silero TTS). Markdown вычищается, эмодзи читаются словами. Если заговорить, пока Юи думает, реплика помечается как перебивание.
- **Личность и своя воля.** Блок `<personality>` в системном промпте задаёт базовый характер. Перед ответом короткий отдельный вызов решает: ДА / НЕТ / ЧАСТИЧНО (`agent/will.py`). Инструмент `stay_silent` позволяет осознанно промолчать.
- **Самоотчёт эмоций.** Модель помечает ответ тегом `<emotion>имя, интенсивность</emotion>`; есть заготовка WebSocket-моста для аватара.
- **Управление Windows.** Запуск и закрытие приложений, ввод текста (через буфер обмена), горячие клавиши, ожидание (не дольше 300 с).
- **Зрение.** Скриншот экрана, просмотр картинки с диска, зум на область. Картинка передаётся модели отдельным сообщением и не хранится в истории.
- **Интернет.** Поиск через DuckDuckGo (`ddgs`) и чтение страниц (`trafilatura`). Содержимое страниц оборачивается в `<web_content>` и считается данными, а не командами.
- **Долговременная память (RAG 2.0).** Факты в `.md`-файлах, гибридный поиск: векторный (`multilingual-e5-base`) + BM25 + бонус за свежесть. У фактов есть уровень доверия от −1 (опровергнуто) до 1 (подтверждено). Факты из диалога извлекаются автоматически.
- **Душа (Soul System).** Перед каждым ходом `SoulManager` собирает из памяти факты о пользователе, черты и предпочтения Юи и последние рефлексии.
- **Своя жизнь в паузах.** Когда к Юи какое-то время не обращаются (за компьютером при этом можно работать), она размышляет сама — полноценным «внутренним ходом» в несколько шагов: думает, ищет в интернете, сохраняет выводы в память, а если захочет — говорит вслух (`speak_aloud`). Мысли видны в консоли (`[YUI ДУМАЕТ]`), не озвучиваются и остаются в истории как `<inner_thought>`. Бывает двух видов: спонтанные мысли (`AutonomyManager`) и рефлексия над свежими фактами памяти (`ReflectionManager`). Стоит заговорить — Юи прерывает размышления и отвечает. Если включено, раз в несколько циклов идёт «сон» — консолидация памяти.
- **Бережное отношение к KV-кэшу.** Системный промпт статичен, всё изменчивое (время, железо, статус памяти, soul patch) приходит в хвосте, в `<injected_context>`, поэтому llama.cpp переиспользует кэш между ходами.

## Как проходит один ход

1. Ввод (голос или текст) попадает в очередь.
2. Параллельно собираются soul patch и подходящие факты из памяти; они вставляются в сообщение пользователя.
3. Проверка воли: хочет ли Юи за это браться.
4. Запрос к `llama-server` (OpenAI-совместимый `/v1/chat/completions`, стриминг, нативный function calling). Короткие реплики идут с меньшим лимитом токенов, задачи — с большим.
5. Если модель вызвала инструменты — они выполняются, результат возвращается модели, цикл повторяется (до 10 шагов).
6. Финальный ответ озвучивается, сессия сохраняется в `sessions/latest.json`, из диалога извлекаются факты в память.

## Структура

```
scripts/
├── config.py           # все настройки: пути, LLM, TTS/STT, память, флаги функций
├── agent/
│   ├── loop.py         # точка входа и основной цикл хода
│   ├── prompt.py       # статичный системный промпт, динамическое состояние
│   ├── context.py      # сжатие контекста, извлечение фактов, injected_context
│   ├── parser.py       # разбор стрима: ответ, рассуждения, tool calls, эмоция
│   ├── executor.py     # выполнение инструментов, озвучка, speech_text()
│   ├── will.py         # проверка «хочу ли я за это браться»
│   ├── emotion.py      # эмоции и WebSocket-мост (заглушка)
│   ├── autonomy.py     # спонтанные мысли при бездействии
│   └── session.py      # сохранение/загрузка истории
├── tools/
│   ├── registry.py     # схемы инструментов и их обработчики
│   ├── control.py      # управление Windows
│   ├── vision.py       # скриншоты, картинки, зум
│   └── web.py          # поиск и чтение страниц
├── memory/
│   ├── manager.py      # хранение и поиск фактов, confidence, дедупликация
│   ├── vector.py       # векторный индекс (SentenceTransformer)
│   ├── reflection.py   # рефлексия и сон-консолидация
│   └── soul.py         # сборка soul patch
├── speech/
│   ├── stt.py          # faster-whisper
│   └── tts.py          # Silero
└── utils/              # общий HTTP-клиент, замер задержек
```

Подробная карта архитектуры для людей и агентов — в [`docs/CODEMAPS/`](docs/CODEMAPS/).

## Требования

- **ОС:** Windows (`pygetwindow`, `keyboard`, `nvidia-smi`).
- **Python:** 3.10+ (разрабатывается на 3.12).
- **GPU:** NVIDIA. Проект настроен под RTX 3060 12 GB + 32 GB RAM.
- **LLM-сервер:** `llama-server` на `127.0.0.1:8080`. Сейчас используется форк [atomic-llama-cpp-turboquant](https://github.com/AtomicBot-ai/atomic-llama-cpp-turboquant) (TurboQuant-квантование KV-кэша + MTP) и MoE-модель Qwen3.6-35B-A3B (APEX-квант с MTP-тензорами), ~25 ток/с. Подойдёт и обычный llama.cpp с любой моделью, поддерживающей function calling.

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Cchebyrekk/YuiSoul.git
   cd YuiSoul
   ```

2. Создайте окружение и поставьте зависимости. `torch` из PyPI ставится в CPU-сборке; для GPU сначала поставьте его с [pytorch.org](https://pytorch.org) под свою версию CUDA:
   ```bash
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   ```

3. Положите модель в `models/` и запустите `llama-server`. Рабочая конфигурация для 12 GB VRAM:
   ```bash
   llama-server -m models\Qwen3.6-35B-A3B-Uncensored-Genesis-MTP-APEX-Compact.gguf ^
     -ngl 999 --n-cpu-moe 30 -c 65536 ^
     --cache-type-k turbo4 --cache-type-v turbo3 ^
     --spec-type draft-mtp --spec-draft-n-max 2 --parallel 1 ^
     -t 6 -tb 6 -b 2048 -ub 512 --flash-attn on ^
     --port 8080 --host 127.0.0.1
   ```
   Флаги `turbo*` и `draft-mtp` есть только в форке; на mainline llama.cpp уберите их. `--parallel 1` обязателен для MTP — поэтому фоновые LLM-вызовы ждут, пока идёт основной ответ.

4. Запустите Юи из корня репозитория:
   ```bash
   python -m scripts.agent.loop
   ```
   Пишите в консоль или говорите в микрофон. `Ctrl+C` — выход с сохранением сессии.

При первом запуске скачаются модель Silero (`scripts/speech/silero_model.pt`), эмбеддинги `multilingual-e5-base` и модель whisper.

## Настройка

Всё в `scripts/config.py`. Самое полезное:

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `LLM_MODEL_PATH`, `LLM_PORT` | Qwen3.6 APEX, 8080 | модель и порт сервера |
| `WILL_CHECK_ENABLED` | `True` | проверка воли перед ответом |
| `THINK_ON_TASKS_ONLY` | `True` | рассуждения модели и проверка воли только для задач («найди», «напиши»…); обычный разговор — сразу ответ (~3 с до голоса вместо ~15) |
| `FACT_EXTRACTION_IDLE_DELAY` | 15 с | извлечение фактов из диалога — только после паузы в разговоре, обрывается, если заговорить |
| `STT_LANGUAGES`, `STT_LANGUAGE` | `("ru", "en")`, `ru` | на каких языках можно говорить и язык по умолчанию. Язык каждой фразы определяет Whisper tiny (~0.3 с), переключение «липкое» — только при уверенности ≥ `STT_LANGUAGE_MIN_CONFIDENCE` |
| `TTS_SPEAKER_RU`, `TTS_SPEAKER_EN` | `xenia`, `en_21` | голоса Silero. Английский — модель `scripts/speech/silero_model_en.pt` (v3_en, 54.5 МБ, [models.silero.ai](https://models.silero.ai/models/tts/en/v3_en.pt)); без неё английские фразы не озвучиваются |
| `STT_SILENCE_BLOCKS` | 5 | сколько блоков тишины по 0.3 с ждать конца фразы |
| `SILENCE_NUDGE_CHANCE` | `0.15` | как часто напоминать о праве промолчать (0 — никогда) |
| `VISION_ENABLED`, `WEB_ENABLED` | `True` | зрение и интернет |
| `ENABLE_AUTONOMY` | `True` | спонтанные мысли, когда к Юи не обращаются |
| `AUTONOMY_IDLE_THRESHOLD`, `AUTONOMY_MIN_INTERVAL` | 180 с, 600 с | через сколько тишины мысль и как часто (без ответа — всё реже) |
| `ENABLE_REFLECTION` | `True` | фоновая рефлексия над памятью |
| `REFLECTION_IDLE_THRESHOLD`, `REFLECTION_MIN_INTERVAL` | 300 с, 1200 с | через сколько тишины и как часто |
| `AUTONOMY_MAX_STEPS`, `REFLECTION_MAX_STEPS` | 6, 8 | сколько шагов может длиться размышление |
| `AUTONOMY_ALLOW_PC_CONTROL` | `False` | разрешить в размышлениях печать, горячие клавиши, запуск/закрытие программ |
| `ENABLE_SLEEP_CONSOLIDATION` | `False` | «сон»: сжатие и чистка памяти раз в 3 цикла рефлексии |
| `WHISPER_MODEL_SIZE`, `WHISPER_DEVICE` | `small`, `cpu` | распознавание речи |
| `FAST_*` / `DEEP_*` | 0.5·1024 / 0.6·2048 | температура и лимит токенов для реплик и задач |

## Память

Хранится в `memory/` обычными `.md`-файлами, по одному факту в строке, вида `категория/тема.md`.

- **Доверие к фактам:** необязательный префикс `(c=0.90)`. `−1` — опровергнуто, `0` — предположение (по умолчанию), `1` — подтверждённый «якорь», который консолидация не трогает.
- **Дедупликация:** косинусная близость > 0.90 или коэффициент Жаккара ≥ 0.4 внутри файла.
- **Характер Юи:** `system/yui/yui_character.md` и `system/yui/yui_preferences.md` — их пишет она сама.
- **Индекс:** `memory/vectors.npy` + `metadata.json`.
- **Служебные запросы** `search_memory`: `__tree__` — структура папок, `__all__` — вся память, `FILE:путь` — конкретный файл.

## Тесты

```bash
pip install pytest pytest-cov
python -m pytest --cov=scripts
```

Тесты в `tests/` не нужны ни llama-server, ни микрофон, ни модель эмбеддингов: LLM подменяется поддельным стримом, эмбеддинги — «мешком слов», память и сессия пишутся во временные папки, любой настоящий HTTP-запрос роняет тест. Покрыты память и векторный индекс, рефлексия и автономия, цикл хода (обычный и внутренний), разбор ответа модели, инструменты, STT-логика. Не покрыты вживую: озвучка Silero и сам запуск со всеми потоками. `scripts/tests/tts_t.py` — ручная проверка озвучки.

## Ограничения

- Только Windows.
- Папки `scripts/ui` и `scripts/game` — заготовки.
- Uncensored-модель почти не отказывает сама — отказы и «своё мнение» держатся на промпте и проверке воли.
